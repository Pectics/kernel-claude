# OpenClaw UI 和媒体系统架构

## 1. Web 界面 (web/)

### 1.1 技术栈

- **核心框架**: 基于 WhatsApp Web API (@whiskeysockets/baileys)
- **认证机制**: 多文件认证存储，支持 QR 码登录
- **媒体处理**: 支持 HTTP/HTTPS 远程文件和本地文件读取
- **安全控制**: SSRF 防护，本地路径白名单验证

### 1.2 API 接口

| 接口 | 功能 |
|------|------|
| `createWaSocket()` | 创建 WhatsApp Web 连接 |
| `loadWebMedia()` | 加载并优化媒体文件 |
| `auth-store.ts` | 处理用户认证状态 |
| `monitor-inbox` | 监控收件箱消息 |

### 1.3 页面结构

| 模块 | 文件 | 功能 |
|------|------|------|
| 登录模块 | `login.ts` | 处理 QR 码登录流程 |
| 媒体模块 | `media.ts` | 媒体文件处理和优化 |
| 会话模块 | `session.ts` | WebSocket 连接管理 |
| 自动回复 | `auto-reply` | 自动回复系统 |

## 2. 终端界面 (tui/)

### 2.1 TUI 实现

- **技术栈**: 自定义终端 UI 框架
- **组件系统**:
  - `components/` - TUI 组件库
  - `theme/` - 主题系统

**交互功能**:

- 命令历史记录
- 表格渲染
- 进度条显示
- 颜色主题支持

### 2.2 CLI 命令 (cli/)

- **参数解析**: `argv.ts` - 命令行参数解析
- **命令处理**:
  - 支持布尔标志和值标志
  - 根选项处理
  - 子命令路由
  - 参数验证

## 3. 浏览器集成 (browser/)

### 3.1 浏览器自动化

- **CDP 协议**: Chrome DevTools Protocol 集成

### 3.2 扩展支持

- **调试工具**: 浏览器调试和管理接口

## 4. 媒体处理 (media/)

### 4.1 媒体文件处理

**图像处理**:
| 功能 | 描述 |
|------|------|
| 多格式支持 | JPEG, PNG, HEIC, GIF |
| 自动优化 | 压缩、调整大小 |
| EXIF 修正 | 方向修正 |
| Alpha 通道 | 保留透明度 |

**音频处理**:
- 标签提取
- 格式转换

**视频处理**:
- 基础视频操作支持

### 4.2 媒体理解 (media-understanding/)

**AI 分析能力**:
- 图像识别和理解
- 音频转录
- 视频内容分析
- 文档解析

**处理流程**:
- 并发控制
- 缓存机制
- 错误处理
- 结果格式化
